** Narrowing in consult-buffer

Press ~<~ inside ~consult-buffer~, then a letter to filter by type:
- ~b~ — open buffers
- ~f~ — recent files
- ~p~ — project files

** The embark-export / wgrep workflow

The most powerful search-and-replace flow in this config:

1. ~M-s r~ — start ~consult-ripgrep~
2. ~C-c C-e~ (or ~embark-export~) — export all results to a ~grep-mode~ buffer
3. ~C-c C-p~ — make the grep buffer editable (wgrep)
4. Edit freely — changes apply across all matched files
5. ~C-c C-c~ — commit all edits; ~C-c C-k~ to abort

** TODO Keyword Flow

#+BEGIN_EXAMPLE
TODO → GROOM → NEXT → DOING → WAIT → DONE / HALTED
PROJECT → ACTIVE → PAUSED → DONE / HALTED
#+END_EXAMPLE

WIP limit: max 3 ~DOING~ at any time. Use ~NEXT~ for "ready to start"
and ~DOING~ only for active work. ~GROOM~ mirrors the JIRA grooming
workflow. ~HALTED~ is for abandoned items (not deleted, for the record).

** Tags

- ~:@work:~ — work context. Agenda views filter on this.
- ~:@errand:~, ~:@home:~, ~:@computer:~ — GTD context tags.
- ~:blocked:~ — used on JIRA tasks instead of ~WAIT~ state.

** Format on Save (apheleia)

Runs automatically on save for configured modes. Formats a copy of the
buffer and applies a patch — point and undo history are preserved.

| Mode                                      | Formatter      |
|-------------------------------------------+----------------|
| ~nix-mode~                                | nixfmt         |
| ~clojure-mode~, ~clojurec-mode~, ~clojurescript-mode~ | zprint |
| ~yaml-mode~, ~json-mode~                  | prettier       |
| ~terraform-mode~                          | terraform fmt  |

To disable for a single save: ~M-x apheleia-mode~ toggles it off for
the current buffer.

* Version Control (magit)

| Key       | Command                                       |
|-----------+-----------------------------------------------|
| ~C-x g~   | ~magit-status~                                |
| ~C-c g~   | ~magit-dispatch~                              |
| ~C-c f~   | ~magit-file-dispatch~                         |

diff-hl shows per-line git status in the fringe; updates on magit
refresh. ~magit-wip-mode~ is on — working tree snapshots are saved
to ~refs/wip/*~ on every commit/checkout. To clean them up:

#+BEGIN_SRC sh
git for-each-ref --format='%(refname)' refs/wip/ | xargs -r git update-ref -d
#+END_SRC
